==========================================
 TFBSM 期权交易系统 - 使用说明 (v7)
==========================================

【重要】必须先解压再运行！
  不要直接在压缩包里双击运行，
  右键压缩包 -> "解压到当前文件夹"（Extract Here）
  得到一个文件夹后，进入文件夹再运行。

【如何启动】
  双击 "启动.bat"
  等待 10~30 秒（首次运行需解压环境，可能更久）
  浏览器自动打开系统页面
  如果没有自动打开，手动访问: http://127.0.0.1:8000

【v7 更新内容】：
  1. 修复 K 线图不显示问题（ECharts K线遇到空占位数据崩溃）
  2. 新增 300ETF 价格预测（GRU 模型，K线图右侧粉色预测线 + 置信区间）
  3. 期权链报价面板：市场价/模型价/偏差/IV/信号 一目了然
  4. 净持有成本 q 校准（分红+融券成本，每日自动测算）
  5. 非交易时段自动跳过校准（9:30-11:30、13:00-15:00 正常校准）
  6. 3D 波动率曲面（WebGL，可拖拽旋转）
  7. 真实新浪行情数据源，全市场期权链

【使用时间】
  校准运行在交易时段进行（9:30-11:30、13:00-15:00）
  盘后和周末数据无更新，系统自动跳过校准。

【Windows 蓝色弹窗（SmartScreen）】
  如果出现 "Windows 已保护你的电脑"
  点击 "更多信息" -> "仍要运行"

【杀毒软件误报】
  本程序为 Python 编写的本地服务，首次运行时如被杀毒软件拦截
  请选择"允许/信任"。

【如何停止系统】
  关闭黑色命令行窗口即可停止服务。

【系统目录】
  data/    - 行情数据与数据库
  models/  - 模型文件
  static/  - 前端页面
  logs/    - 运行日志
